# Getting Started with Xan's Space Tools

Welcome to Xan's Space Tools - Your Star Citizen trading companion app! This guide will help you get up and running quickly.

## 🚀 Quick Start for End Users (Production Build)

If you downloaded the pre-built executable, follow these steps:

### Step 1: Download and Run

1. Download the latest release for your platform:
   - **Windows**: `Xan's Space Tools 1.0.0.exe` (portable executable)
   - **macOS**: `Xan's Space Tools-1.0.0.dmg`
   - **Linux**: `Xan's Space Tools-1.0.0.AppImage` or `.deb` package

2. Run the executable (no installation required for portable version)

3. On first launch, the app will automatically create a `config.json` file in your app data directory

### Step 2: Get Your API Key

1. Visit https://uexcorp.space/api/apps
2. Log in to your UEX account
3. Create a new app (if you haven't already)
4. Copy your **API Key** (Bearer Token)

### Step 3: Configure the App

1. In the app, go to the **Settings** tab
2. In the **API Configuration** section:
   - Paste your **UEX API Key** (Bearer Token) in the "UEX API Key" field
   - Optionally enter your **Secret Key** (for creating marketplace listings)
     - Get it from https://uexcorp.space/account (log in to view your account)
3. Click **Save Settings**

That's it! The app is now configured and ready to use! 🎉
